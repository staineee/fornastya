# Сайт для Насти

## Что нужно заменить

### Фотографии

Положи свои фотографии в папку `images` и назови их:

- `hero.jpg` — главное фото на первом экране
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`
- `final.jpg` — фото на финальном экране

Если хочешь меньше фотографий — можно использовать одну и ту же фотографию в нескольких местах.

### Музыка

Положи MP3-файл в:

`music/music.mp3`

После открытия сайта нажми кнопку `MUSIC OFF` в правом нижнем углу.

Важно: браузеры обычно не разрешают автоматически запускать музыку без действия пользователя, поэтому музыка включается кнопкой.

### Тексты

Все основные тексты находятся в `index.html`.

Самые важные места:
- `THINGS I LOVE` — список того, что ты любишь в Насте
- `OUR ARCHIVE` — подписи к фотографиям
- `A LETTER` — твоё письмо
- `FIN.` — финальная фраза

### Как открыть

Просто дважды нажми `index.html`.

Или в VS Code установи расширение Live Server и нажми:
`ПКМ по index.html → Open with Live Server`
